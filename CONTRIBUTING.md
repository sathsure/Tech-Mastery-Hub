\# Contributing to Tech-Mastery-Hub



Thank you for contributing.



\## Core Principle



Avoid duplicating concepts.



A technical concept should have one canonical source under:



`knowledge/concepts/`



Other areas should reference that concept.



\## Content Types



\### Roadmap



Answers:



> What should I learn?



\### Concept



Answers:



> What is this and how does it work?



\### Masterclass



Answers:



> How do I learn this deeply?



\### Interview



Answers:



> Can I explain it in an interview?



\### Practice



Answers:



> Can I apply this knowledge?



\### Project



Answers:



> Can I build something using these concepts?



\### Visual Note



Answers:



> Can this concept be understood visually?



\## Before Adding Content



1\. Search for an existing concept.

2\. Reuse it if it already exists.

3\. Add a new concept only when necessary.

4\. Link related concepts.

5\. Add references where appropriate.

6\. Avoid copying third-party copyrighted content.



\## AI-Assisted Contributions



AI-generated changes should be reviewed before merging.



The AI should propose changes rather than silently modifying the canonical knowledge base.
