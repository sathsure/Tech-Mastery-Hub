# AI Tutor Retrieval Specification`n`n## 1. Retrieval Objective`n`nRetrieve the smallest sufficient set of trusted repository evidence needed to answer accurately and transparently.`n`n## 2. Retrieval Stages`n`nIntent -> Canonical Match -> Candidate Resources -> Relationship Expansion -> Relevance Ranking -> Context Selection -> Source-Aware Context`n`n## 3. Canonical Anchoring`n`nWhen a canonical concept exists, anchor retrieval on it, retrieve the canonical page, inspect approved relationships, and retrieve useful associated resources.`n`nWhen no canonical concept exists, retrieve resources, identify the repository gap, and follow unknown-topic behavior without fabricating repository coverage.`n`n## 4. Ranking Signals`n`n1. canonical concept match`n2. exact topic match`n3. relevant section match`n4. requested learning mode`n5. approved relationship`n6. content type relevance`n7. semantic similarity`n`n## 5. Context Selection`n`nPrefer authoritative canonical content, directly relevant sections, strongly connected resources, and minimum sufficient context.`n`nAvoid unrelated content, duplicate evidence, excessive expansion, and unnecessary full-document loading.`n`n## 6. Relationship Expansion`n`nOnly canonical-to-canonical and canonical-to-approved-resource relationships may be traversed. Stop when relevance falls, context budget is reached, or additional material no longer improves the answer.`n`n## 7. Source Transparency`n`nEvidence retains source type, repository path where applicable, canonical concept, authority, and relevant section.`n`n## 8. Unknown Topic Behavior`n`nState the repository gap; use related concepts when useful; optionally use permitted external retrieval; clearly distinguish external information; never fabricate repository coverage.`n`n## 9. Retrieval Failure`n`nDistinguish no relevant content, repository retrieval unavailable, external retrieval unavailable, index unavailable, and relationship traversal unavailable. Retrieval failure must not be represented as proof that the repository lacks a topic.

## Authoritative Knowledge Index

The authoritative repository knowledge index is `ai/knowledge-index/content-index.json`.

The retrieval runtime uses this index to locate eligible repository knowledge, canonical concepts, resource-to-concept relationships, and concept-to-concept relationships. The index is metadata and routing information; it is not a substitute for retrieving the underlying repository content.
