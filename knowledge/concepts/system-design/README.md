# System Design

## Purpose

Designing systems that scale: requirements, estimates, building blocks, classic design questions and distributed-systems fundamentals.

## Core Topics

### Building blocks
- Load balancers, CDNs, caches and queues
- Vertical vs horizontal scaling
- SQL vs NoSQL, replication and sharding
- Consistent hashing

### Classic designs
- URL shortener, rate limiter, chat app
- News feed, notification service, file storage

### Distributed systems
- CAP theorem and eventual consistency
- Saga and transactional outbox
- Idempotency, retries, timeouts, circuit breakers
- Distributed locks, leader election, quorum
