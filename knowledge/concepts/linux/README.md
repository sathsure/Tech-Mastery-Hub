# Linux & Shell

## Purpose

Using Linux confidently as a developer: moving around the file system, permissions, processes and services, shell scripts, and finding out why a server is slow.

## Core Topics

### Basics
- File system layout
- Everyday commands

### Permissions & users
- chmod, chown, sudo and root

### Processes & services
- ps, top, kill
- systemd and journalctl

### Shell
- Pipes and redirection
- Scripts, grep, sed, awk
- Environment variables

### Troubleshooting
- CPU, memory, disk, network
- Ports and SSH
