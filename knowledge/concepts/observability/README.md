# Observability & SRE

## Purpose

Seeing inside running systems and keeping them reliable: the three pillars of observability and the core SRE practices.

## Core Topics

### Observability
- Logs, metrics, traces
- Structured logging
- Distributed tracing, OpenTelemetry

### Metrics & alerts
- Golden signals, RED, USE
- Percentile latency
- Good alerts

### SRE practices
- SLI, SLO, SLA, error budgets
- Incident handling and postmortems
- MTTD/MTTR, toil, chaos engineering
