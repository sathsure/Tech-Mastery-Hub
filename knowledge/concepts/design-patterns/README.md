# Design Patterns & SOLID

## Purpose

Writing code that is easy to change: the SOLID principles and the most used creational, structural and behavioral patterns, with Java examples.

## Core Topics

### Principles
- Single Responsibility, Open/Closed, Liskov, Interface Segregation, Dependency Inversion
- Composition over inheritance, DRY, KISS, YAGNI

### Creational
- Singleton, Factory, Builder, Prototype

### Structural
- Adapter, Decorator, Proxy, Facade

### Behavioral
- Strategy, Observer, Template Method, Chain of Responsibility, Command
