# Data Structures and Algorithms (DSA)

## Purpose

Canonical DSA knowledge for coding interviews, with examples in Python.

## Core Topics

### Complexity
- Time and space complexity
- Big O, Big Omega, Big Theta
- O(1), O(log n), O(√n), O(n), O(n log n), O(n²), O(n³), O(2ⁿ)
- Amortized complexity and Python operation costs

### Problem-Solving Patterns
- Hash maps and sets
- Two pointers and sliding window
- Binary search
- Stacks, heaps and intervals
- Linked lists (fast and slow pointers)
- Trees and graphs (DFS, BFS)
- Dynamic programming
