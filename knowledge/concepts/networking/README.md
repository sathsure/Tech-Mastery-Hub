# Networking & HTTP

## Purpose

How the web works underneath: what happens when you open a URL, DNS, TCP/UDP, HTTP versions, TLS, cookies, CORS and real-time communication.

## Core Topics

### The network
- DNS, TCP vs UDP, the TCP handshake
- OSI and TCP/IP layers

### HTTP
- Methods, status codes, HTTP/1.1 vs 2 vs 3
- HTTPS/TLS, cookies, CORS, caching headers

### APIs and real time
- WebSockets vs SSE vs polling
- REST vs GraphQL vs gRPC, proxies
