# Caching & Redis

Making systems fast with caches: strategies, eviction, invalidation and cache problems, plus Redis data types, persistence and Spring Boot caching.

## Core Topics

### Caching
- Cache-aside, write-through, write-behind
- Eviction policies and TTL
- Stampede, penetration, avalanche

### Redis
- Data types and use cases
- Persistence (RDB, AOF), replication, Sentinel, Cluster
- @Cacheable with Spring Boot
