# AI & LLMs for Developers — One-liners

> The most asked questions, each answered in one sentence.

1. **What is an LLM?** — A large neural network trained on text to predict the next token.
2. **What is a token?** — A piece of a word; models read, write and charge by tokens.
3. **What is a context window?** — The maximum number of tokens a model can consider at once.
4. **What is temperature?** — A setting that controls randomness: low is focused, high is creative.
5. **What is a hallucination?** — A confident answer that is false.
6. **What is a system prompt?** — Standing instructions that guide the model for the whole conversation.
7. **What is few-shot prompting?** — Putting a few examples in the prompt to show the expected answer.
8. **What is an embedding?** — A list of numbers representing meaning, so similar texts are close together.
9. **What is cosine similarity?** — A measure of how similar two embeddings are by the angle between them.
10. **What is a vector database?** — A database that stores embeddings and finds the nearest ones quickly.
11. **What is RAG?** — Retrieving relevant documents and adding them to the prompt so the model answers from them.
12. **What is chunking?** — Splitting documents into smaller pieces before embedding them.
13. **What is hybrid search?** — Combining vector search with keyword search.
14. **What is a reranker?** — A model that reorders retrieved chunks by relevance.
15. **RAG vs fine-tuning?** — RAG adds up-to-date knowledge; fine-tuning changes the model's style or behaviour.
16. **What is tool (function) calling?** — The model requests a function call and uses its result in the answer.
17. **What is an AI agent?** — An LLM that loops through thinking, using tools and checking results until a task is done.
18. **What is MCP?** — Model Context Protocol, a standard for connecting AI apps to tools and data.
19. **What is prompt injection?** — Untrusted text trying to override the model's instructions.
20. **What is LLM-as-judge?** — Using a model with a rubric to grade another model's answers.
21. **What is LoRA?** — A cheap fine-tuning method that trains small adapter weights.
22. **What is quantization?** — Storing model weights with fewer bits to make the model smaller and faster.
