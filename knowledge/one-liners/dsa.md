# DSA (Python) — One-liners

> The most asked questions, each answered in one sentence.

1. **What is Big O?** — A way to describe how running time or memory grows as the input gets bigger.
2. **Time vs space complexity?** — Time measures steps taken; space measures extra memory used.
3. **Array vs linked list?** — Arrays give fast access by index; linked lists give fast inserts and deletes at known nodes.
4. **Stack vs queue?** — A stack is last in, first out; a queue is first in, first out.
5. **How does a hash table work?** — A hash function turns a key into a bucket index for O(1) average lookups.
6. **What is a hash collision?** — Two keys landing in the same bucket.
7. **What is a heap?** — A tree where the parent is always smaller (min-heap) or larger (max-heap) than its children.
8. **What is a BST?** — A binary tree where left children are smaller and right children are larger than the node.
9. **BFS vs DFS?** — BFS explores level by level (shortest paths); DFS goes deep first (paths, backtracking).
10. **What is binary search?** — Repeatedly halving a sorted range to find a value in O(log n).
11. **What is the two-pointer technique?** — Moving two indexes through the data, often from both ends of a sorted array.
12. **What is a sliding window?** — A moving range over a contiguous part of an array or string.
13. **What is dynamic programming?** — Solving a problem by storing and reusing answers to smaller overlapping subproblems.
14. **Memoization vs tabulation?** — Memoization is top-down with caching; tabulation is bottom-up filling a table.
15. **What is greedy?** — Taking the best choice at each step, hoping it leads to the best overall answer.
16. **What is backtracking?** — Trying choices, and undoing them when they lead nowhere.
17. **What is a trie?** — A tree of characters used for fast prefix searches.
18. **What is a topological sort?** — Ordering tasks so each comes after its dependencies.
19. **What is union-find?** — A structure that tracks which items are in the same group.
20. **What does Dijkstra's algorithm do?** — Finds the shortest paths from one node in a graph with non-negative weights.
21. **Merge sort vs quick sort?** — Merge sort is always O(n log n) but needs extra memory; quick sort is in place but O(n²) in the worst case.
22. **What is a stable sort?** — One that keeps equal items in their original order.
