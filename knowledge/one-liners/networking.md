# Networking & HTTP — One-liners

> The most asked questions, each answered in one sentence.

1. **TCP vs UDP?** — TCP is reliable and ordered; UDP is faster but doesn't guarantee delivery or order.
2. **What is the TCP three-way handshake?** — SYN, SYN-ACK, ACK to open a connection.
3. **What are the OSI layers?** — Physical, Data link, Network, Transport, Session, Presentation, Application.
4. **What is DNS?** — The system that turns domain names into IP addresses.
5. **A vs CNAME record?** — An A record points a name to an IP; a CNAME points a name to another name.
6. **What is a TTL in DNS?** — How long a DNS answer may be cached.
7. **What is NAT?** — Translating many private IP addresses to one public IP.
8. **What is DHCP?** — A protocol that gives devices an IP address automatically.
9. **What is a port?** — A number that identifies which program on a machine receives the traffic.
10. **HTTP vs HTTPS?** — HTTPS is HTTP encrypted with TLS.
11. **What does TLS do?** — It encrypts traffic, protects it from tampering and proves the server's identity.
12. **What is a TLS certificate?** — A file that binds a domain to a public key, signed by a trusted authority.
13. **HTTP/1.1 vs HTTP/2?** — HTTP/2 sends many requests at once over one connection with compressed headers.
14. **What is HTTP/3?** — HTTP over QUIC (on UDP), with faster setup and no head-of-line blocking from TCP.
15. **What is CORS?** — A browser mechanism that lets servers allow requests from other origins.
16. **What is a preflight request?** — An `OPTIONS` request the browser sends before certain cross-origin requests.
17. **What are `HttpOnly` and `Secure` cookies?** — `HttpOnly` hides the cookie from JavaScript; `Secure` sends it only over HTTPS.
18. **Latency vs bandwidth?** — Latency is delay; bandwidth is how much data can flow at once.
19. **Router vs switch?** — A switch connects devices within a network; a router connects networks.
20. **What is a subnet?** — A range of IP addresses, written like `10.0.1.0/24`.
