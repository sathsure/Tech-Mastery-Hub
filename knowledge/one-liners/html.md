# HTML — One-liners

> The most asked questions, each answered in one sentence.

1. **What is semantic HTML?** — Using tags that describe meaning (`header`, `nav`, `article`) so browsers, search engines and screen readers understand the page.
2. **What does `<!DOCTYPE html>` do?** — It tells the browser to use modern standards mode.
3. **Block vs inline elements?** — Block elements start on a new line and take full width; inline elements flow inside text.
4. **`id` vs `class`?** — An `id` must be unique on the page; a `class` can be used on many elements.
5. **`defer` vs `async`?** — Both download scripts in the background; `defer` runs them in order after parsing, `async` runs each as soon as it loads.
6. **Why use a `<label>`?** — It names the input for screen readers and makes the label clickable.
7. **What is the viewport meta tag for?** — It makes the page scale correctly on mobile screens.
8. **Why does `alt` text matter?** — Screen readers read it, and it shows if the image fails to load.
9. **GET vs POST in forms?** — GET puts data in the URL (searches); POST sends it in the body (logins, creating data).
10. **What are `data-*` attributes?** — Custom attributes for storing extra data, read in JS through `element.dataset`.
11. **Canvas vs SVG?** — Canvas draws pixels with JavaScript; SVG describes shapes that stay sharp at any size.
12. **What is ARIA?** — Attributes that add accessibility information when plain HTML can't express it.
13. **`<b>` vs `<strong>`?** — `<b>` only looks bold; `<strong>` marks the text as important.
14. **What does `loading="lazy"` do?** — It delays loading an image until it is near the screen.
15. **What is the DOM?** — The tree of objects the browser builds from HTML, which JavaScript can read and change.
16. **`<section>` vs `<article>` vs `<div>`?** — `article` stands on its own, `section` groups related content with a heading, `div` has no meaning.
17. **What is `srcset`?** — A list of image sizes so the browser can pick the best one for the screen.
18. **What does `tabindex` do?** — It controls whether and in what order an element can get keyboard focus.
19. **What are Open Graph tags?** — `og:` meta tags that control the title and image shown when a link is shared.
20. **What is a `<template>` element?** — HTML that isn't rendered until JavaScript copies it into the page.
