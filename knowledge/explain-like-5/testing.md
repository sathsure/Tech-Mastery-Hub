# Testing — Explain Like I'm 5

> Hard ideas as everyday pictures, then what they really mean.

## Unit test
🔩 Checking each LEGO brick isn't broken before building.
**Really:** testing one small piece alone.

## Integration test
🧱 Checking the bricks actually snap together.
**Really:** testing real pieces working together.

## End-to-end test
🏰 Playing with the finished castle like a kid would.
**Really:** using the whole app like a real user.

## Test pyramid
🍰 A cake: a thick base of unit tests, a middle layer of integration, a small cherry of E2E on top.
**Really:** many fast tests, few slow ones.

## Mock
🎭 A stunt double in a film: looks like the actor, does exactly what the script says.
**Really:** a fake object you program and check.

## TDD
🎯 Drawing the target first, then throwing darts until you hit it.
**Really:** write a failing test, then the code to pass it.

## Flaky test
🎲 A smoke alarm that rings randomly — soon nobody trusts it.
**Really:** a test that passes or fails without code changes.

## Code coverage
🗺️ Marking which rooms of a house you walked through — not whether you checked anything in them.
**Really:** which code ran during tests, not whether it was checked well.
