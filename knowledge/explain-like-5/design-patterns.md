# SOLID & Design Patterns — Explain Like I'm 5

> Hard ideas as everyday pictures, then what they really mean.

## Single Responsibility
🔪 A knife cuts; a spoon stirs. A spork does both badly.
**Really:** one class, one job.

## Open/Closed
🔌 A power strip: plug in a new device without rewiring the house.
**Really:** add features by adding code, not editing old code.

## Liskov Substitution
🚗 Any rental car should drive the same way: steering, brake, accelerator — no surprises.
**Really:** a child class must work wherever the parent works.

## Dependency Inversion
🔋 A torch takes "any AA battery", not one special brand.
**Really:** depend on interfaces, not specific classes.

## Singleton
🏫 A school has only one principal.
**Really:** exactly one instance of a class.

## Factory
🍦 Ask the ice-cream shop for "chocolate" — you don't make it yourself.
**Really:** a method that creates the right object for you.

## Builder
🍔 Building a burger step by step: bun, patty, cheese, sauce — skip what you don't want.
**Really:** construct a complex object one part at a time.

## Strategy
🗺️ Choosing to go by bus, cab or bike to the same place.
**Really:** swap algorithms behind one interface.

## Observer
🔔 Subscribing to a YouTube channel: you're notified whenever there's a new video.
**Really:** subscribers are told when something changes.

## Adapter
🔌 A travel plug adapter that lets an Indian plug fit a UK socket.
**Really:** make one interface work with another.

## Decorator
🎂 Adding icing and candles to a plain cake — still a cake, now fancier.
**Really:** wrap an object to add behaviour.
