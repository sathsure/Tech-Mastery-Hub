# Linux & Shell — Explain Like I'm 5

> Hard ideas as everyday pictures, then what they really mean.

## Shell
🗣️ Talking to the computer by typing short orders instead of clicking.
**Really:** a program that runs the commands you type.

## Permissions (rwx)
🏠 House keys: some people can look in (read), some can rearrange (write), some can use the kitchen (execute).
**Really:** read, write, execute rights for owner, group and others.

## Process
🎬 A film playing on a TV — the film file is the program; playing it is the process.
**Really:** a running instance of a program.

## Pipe `|`
🔗 A bucket brigade: each person passes the bucket to the next.
**Really:** one command's output becomes the next one's input.

## Signals (`kill`)
📣 SIGTERM is asking "please finish and leave". SIGKILL is carrying them out of the room.
**Really:** messages to processes; 15 is polite, 9 is forced.

## Soft link
🪧 A signpost pointing to a shop — if the shop closes, the sign points to nothing.
**Really:** a shortcut to a path that breaks if the target is removed.

## cron
⏰ An alarm clock that runs a chore for you every day at the same time.
**Really:** a scheduler for recurring commands.
