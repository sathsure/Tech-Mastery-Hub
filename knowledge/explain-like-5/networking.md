# Networking & HTTP — Explain Like I'm 5

> Hard ideas as everyday pictures, then what they really mean.

## IP address
🏠 A house address so letters reach the right home.
**Really:** a number that identifies a device on a network.

## Port
🚪 Different doors of one building: front door for guests (443), back door for deliveries (22).
**Really:** a number that picks which program receives the traffic.

## DNS
📒 A phone book: look up a friend's name to get their number.
**Really:** turns domain names into IP addresses.

## TCP vs UDP
📦 TCP is registered post: signed for, re-sent if lost, delivered in order. UDP is shouting across the playground: fast, but some words get lost.
**Really:** reliable and ordered vs fast without guarantees.

## Three-way handshake
🤝 "Can you hear me?" — "Yes, can you hear me?" — "Yes!" Then you start talking.
**Really:** SYN, SYN-ACK, ACK before sending data.

## HTTPS / TLS
🔐 Sending a letter in a locked box that only the receiver can open, with an ID card proving who they are.
**Really:** encryption plus server identity via certificates.

## NAT
🏢 One office phone number; the receptionist forwards calls to the right desk extension.
**Really:** many private devices share one public IP.

## Latency vs bandwidth
🛣️ Latency is how long the road is; bandwidth is how many lanes it has.
**Really:** delay vs capacity.
