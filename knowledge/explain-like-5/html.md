# HTML — Explain Like I'm 5

> Hard ideas as everyday pictures, then what they really mean.

## HTML
🦴 The skeleton of a body: it gives the page its shape (head, body, parts). CSS is the clothes; JavaScript is the muscles.
**Really:** HTML is the structure and content of a page.

## Semantic tags
🏷️ Labelled boxes when you move house: "Kitchen", "Books", "Toys" — instead of all boxes saying "Box".
**Really:** tags like `header`, `nav`, `article` tell browsers and screen readers what each part is.

## The DOM
🌳 A family tree drawn from the HTML: parents, children, siblings. JavaScript can add or remove people from the tree.
**Really:** the browser's live tree of the page that code can change.

## `defer` vs `async`
📚 `defer`: read all the homework books after dinner, in order. `async`: read each book the moment it arrives, any order.
**Really:** `defer` runs scripts after parsing, in order; `async` runs each as soon as it loads.

## Accessibility
🚪 A building with ramps and lifts, not just stairs, so everyone can get in.
**Really:** pages that work for screen readers, keyboards and all users.

## Forms
📝 A paper form at the bank: labelled boxes you fill, then hand to the clerk (the server).
**Really:** inputs with labels whose values are sent to a server.
